# Kostenlose Asset-Vorschläge für Knights & Towers

## 1. Tiny Swords – Pixel Frog

**Einsatz:** Hauptstil, Menschen/Player, Gebäude, Terrain, Deko, UI.

**Warum passend:** Tiny Swords hat genau den gewünschten mittelalterlichen Cartoon-/Pixel-Look. Für euer Projekt eignet es sich besonders als optische Richtung.

**Hinweis:** Der Free Pack enthält Human Units, Buildings, Ressourcen, Terrain, Decorations und UI. Das Enemy Pack ist separat und kostenpflichtig. Deshalb ist Tiny Swords super als Stilvorlage und für Spieler/Burg/Map geeignet; für Gegner könnt ihr entweder eigene Recolors nutzen oder CC0-Alternativen nehmen.

## 2. Kenney Medieval RTS

**Einsatz:** Burg, Gebäude, mittelalterliche Props, Terrain/Tiles, Deko.

**Lizenz:** CC0. Attribution ist nicht nötig, aber Kenney-Credit ist nett und wirkt sauber in der Präsentation.

## 3. Kenney Tower Defense Top-Down

**Einsatz:** Türme, Projektile, Weg-/Terrain-Elemente, Effekte, Gegner-Platzhalter.

**Lizenz:** CC0.

## 4. Kenney Fantasy UI Borders

**Einsatz:** Fantasy-HUD, Holz-/Pergament-Panels, Buttons, Menürahmen.

**Lizenz:** CC0.

# Drop-in-Benennung

Das Projekt lädt automatisch diese Dateinamen aus `res://assets/game/`:

| Datei | Verwendung |
|---|---|
| `player.png` | Spieler / Ritter / King |
| `enemy_goblin.png` | Standard-Gegner |
| `enemy_bandit.png` | Bandit-Gegner |
| `enemy_ork.png` | Ork / Tank-Gegner |
| `enemy_boss.png` | Boss-Gegner |
| `tower_archer.png` | Bogenschützen-Turm |
| `projectile_arrow.png` | Pfeil / Projektil |
| `grass_tile.png` | Gras-Kachel für Hintergrund |
| `castle.png` | Burg am Ziel |
| `tree.png` | Baum-Deko |
| `rock.png` | Stein-Deko |

Wenn die Dateien fehlen, benutzt Godot automatisch die eingebauten Mockup-Zeichnungen aus den `_draw()`-Funktionen.
