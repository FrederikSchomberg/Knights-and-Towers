# Drop-in-Assets

Lege eure ausgewählten PNGs aus freien Asset-Packs in diesen Ordner und benennt sie genau so:

- player.png
- enemy_goblin.png
- enemy_bandit.png
- enemy_ork.png
- enemy_boss.png
- tower_archer.png
- projectile_arrow.png
- grass_tile.png
- castle.png
- tree.png
- rock.png

Wenn eine Datei fehlt, zeichnet das Spiel automatisch den bisherigen Mockup-Platzhalter.
Dadurch läuft das Projekt direkt weiter, auch wenn ihr erst nur einzelne Assets ersetzt.

Empfohlene Quellen:

1. Tiny Swords von Pixel Frog
   - Sehr passend zum gewünschten Mittelalter-Cartoon-Stil.
   - Free Pack: Human Units, Buildings, Terrain, Deko, UI.
   - Enemy Pack ist separat/paid.

2. Kenney Medieval RTS
   - CC0, gut für Gebäude, Units, Tiles und Deko.

3. Kenney Tower Defense Top-Down
   - CC0, gut für Türme, Projektile, Effekte und allgemeine TD-Assets.

4. Kenney Fantasy UI Borders
   - CC0, gut für Menü-/HUD-Fenster im Fantasy-Stil.
